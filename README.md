## 项目启动

1. npm install
2. npm run dev
3. 浏览器访问 http://localhost:10086

## 打包

测试环境打包命令 `yarn build:test`

生产环境打包命令 `yarn build:prod`

## git 上传命令

例如 `git commit -m "fix：上传命名"`

'feat', // 新功能 feature

'fix', // 修复 bug

'docs', // 文档注释

'style', // 代码格式(不影响代码运行的变动)

'refactor', // 重构(既不增加新功能，也不是修复 bug)

'perf', // 性能优化

'test', // 增加测试

'chore', // 构建过程或辅助工具的变动

'revert', // 回退

'build' // 打包
